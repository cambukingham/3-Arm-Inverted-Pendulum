# 3-Arm-Inverted-Pendulum
The 3 arm inverted pendulum problem is essentially the regular inverted pendulum problem on steroids; the goal is to design a controller that successfully applies some force (denoted by "u") to an actuator(s) on the inverted pendulum, such that the poles are balanced in an upright position. The problem is, each additional pole adds a severe amount of complexity to the system, therefore requiring methods that can deal with the system's nonlinear attributes. In this scenario, I used a Linear Quadratic Regulator (LQR) to do just that. The gist of it is to use two penalty matrices, Q and R, to calculate an optimal control that uses as little power for actuation as possible, and keeps the states within a reasonable frame. Because we are dealing with a nonlinear system using a linear controller, we have to linearize the system around an operating region using taylor expansion.
